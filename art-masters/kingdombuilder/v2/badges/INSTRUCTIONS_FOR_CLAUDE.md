# 2D Map Badges — player colour instructions

Circular 2D world-map badges. Everything is generated by `map-badges-2d.js` (no dependencies, runs in a browser or Node). Each badge is a 100×100 viewBox SVG; `size` only sets the output width/height.

## Contents
- `map-badges-2d.js` — generator
- `svg/`, `png/` — default set (512px): village, barbarian, forest, quarry, iron, plot, village_1–5, barbarian_1–5
- `png/_example-village_3-blue.png` — example player recolour

## What can be recoloured
| Option | Affects | Default |
|---|---|---|
| `ring` | Outer ring of the **Player Village** badge (`village`, `village_N`) | `#ffffff` |
| `chip` | Level shield fill (`village_N`, `barbarian_N`) | village `#ffffff`, barbarian `#a8322f` |
| `ink`  | Roman numeral colour on the shield | village `#2b2320`, barbarian `#ffffff` |
| `size` | Output px | `512` |

The dark outline (`#2b2320`) and gold inner shield border stay fixed so every colour still reads. Barbarian badges ignore `ring` — keep them red so they always read as enemies.

## Recolouring for a player
```js
const MB = require('./map-badges-2d.js');          // or <script src> → window.MapBadges2D

MB.player('village_3', 'blue');                     // preset
MB.player('village_3', '#8e44ad');                  // any hex; numeral ink picked automatically (dark on light, white on dark)
MB.build('village_3', { ring: '#8e44ad', chip: '#f1c40f', ink: '#2b2320' }); // full control
```
Presets (`MB.PLAYERS`): white, blue, green, yellow, purple, orange, teal, black. Avoid red for players — it's reserved for barbarians.

## Batch-export one player's set (Node)
```js
const fs = require('fs'), MB = require('./map-badges-2d.js');
const colour = 'green';
fs.mkdirSync(`players/${colour}`, { recursive: true });
['village', 1, 2, 3, 4, 5].forEach(l => {
  const key = l === 'village' ? 'village' : 'village_' + l;
  fs.writeFileSync(`players/${colour}/badge-${key}.svg`, MB.player(key, colour, { size: 512 }));
});
```

## PNG export (browser)
```js
function toPng(svg, size) {
  return new Promise(res => { const img = new Image(); img.onload = () => {
    const c = document.createElement('canvas'); c.width = c.height = size;
    c.getContext('2d').drawImage(img, 0, 0, size, size); c.toBlob(res); };
    img.src = 'data:image/svg+xml;charset=utf-8,' + encodeURIComponent(svg); });
}
toPng(MB.player('village_4', 'teal'), 512).then(blob => /* save */ 0);
```
In Node, rasterise the SVG with `sharp` or `resvg-js`.

## Notes for Claude
- Don't edit the art; only pass options. If a new option is needed, add it in `build()` and keep the defaults unchanged.
- Numerals use SVG text (`Trajan Pro`/`Cinzel` → Georgia fallback). For identical rendering everywhere, rasterise on a machine with Cinzel installed, or convert the text to paths.
- Each SVG uses clip-path ids `bcv`, `bcb`, etc. When inlining several badges in one HTML page, prefix those ids per badge to avoid collisions.
- Level 1–5 only; for more levels extend the numeral list `['I','II','III','IV','V']` in `build()`.
